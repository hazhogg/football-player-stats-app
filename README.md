# Football Player Stats App 2025/26

An interactive football player statistics dashboard built with Python and Dash, featuring data from the 2025/26 season.

🔗 **Live App:** https://your-app-name.onrender.com

## Features

- **Attacking Stats** — Top scorers, assists, goals + assists, shots, crosses, and goals per shot
- **Defensive Stats** — Tackles won, interceptions, fouls drawn and committed
- **Goalkeeper Stats** — Saves, save percentage, clean sheets, and goals conceded
- **Player Comparison** — Interactive radar charts to compare multiple players across all categories

## Built With

- [Python](https://www.python.org/)
- [Dash](https://dash.plotly.com/)
- [Plotly](https://plotly.com/)
- [Pandas](https://pandas.pydata.org/)

## Run Locally

1. Clone the repo
   git clone https://github.com/YOUR_USERNAME/football-player-stats-app.git

2. Install dependencies
   pip install -r requirements.txt

3. Run the app
   python playerstatsapp.py

4. Open http://localhost:8050 in your browser
